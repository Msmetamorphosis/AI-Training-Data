**High-quality training data for fine-tuning Large Language Models (LLMs)**  
This repository contains a custom dataset I personally developed for an advanced LLM fine-tuning project. The focus of this dataset is SQL, a critical language for data professionals...crafted to simulate natural, helpful, and domain-relevant conversations between users and an AI assistant.

---

## 📂 What's Inside

### `SQL training data.jsonl`
A JSONL-formatted dataset containing realistic multi-turn dialogues covering SQL topics, such as:

- 🧮 **Window Functions**  
  _"How do I calculate a running total by month?"_

- 🌲 **Hierarchical Queries**  
  _"How do I query a table with parent-child relationships using CTEs?"_

- 🔄 **PIVOT Operations**  
  _"Can you show me how to use the PIVOT function on a sales dataset?"_

- 📊 **Crypto Trade Tracking**  
  _"How do I summarize crypto trades and compare averages per month?"_

- 🪙 **Mining Reward Analysis**  
  _"How do I calculate monthly mining rewards and group by coin type?"_

- 🧠 **Advanced Filtering and Aggregations**  
  _"How can I segment customer transactions and compare daily averages?"_

Each sample was structured to:
- Mimic real-world user queries with follow-up clarification questions
- Demonstrate step-by-step AI assistant guidance
- Teach SQL logic, best practices, and practical business use cases

---

## 🎯 Purpose

This dataset was used in a project to fine-tune a general-purpose LLM into a **domain-aware SQL assistant**. It enabled model evaluation across:

- Helpfulness & relevance
- Step-by-step reasoning
- Multi-turn memory and clarification handling
- SQL accuracy and pattern generalization
